# AI Generation Prompts

## Workflow (read first)

1. **Reference plates first (still images).** Generate R1–R5 below in one still-image model session (Midjourney v7 with `--cref`/`--sref`, Flux 1.1 Pro / Kontext, or Google Imagen / Nano Banana). Pick one approved result per plate and **freeze it**. These frames are the identity and location anchors.
2. **Start frames per shot.** For each AI shot, create a start frame from the relevant reference plates (image editing: "same woman, same room, new pose/props"). Approve every start frame before animating.
3. **Image-to-video.** Animate each approved start frame with the shot prompt below. Recommended: **Google Veo 3** (best realism and lighting, 8 s max — generate and trim), **Kling 2.x** (strong human motion, start+end frame control — use for S13/S15/S16), **Runway Gen-4 / Gen-4 References** (for keeping identity across S05/S07/S13/S15). Generate 3–4 takes per shot; choose on hands, eyes and continuity.
4. **Audio from video models is always discarded.** Veo generates sound — mute it in the edit; it may contain speech. All sound comes from `sound-design.md`.
5. **Never ask a model for text, UI, logos or numbers.** Screens stay unreadable; all typography and UI are added in the edit.
6. Deliver generations at the highest available resolution (1080p minimum, 4K when available), 24 fps; upscale with Topaz Video AI (Proteus/Rhea) only if needed, grain added after the upscale.
